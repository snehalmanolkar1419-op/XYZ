# Daily Expense Tracker

A beginner-friendly expense tracker built with HTML, CSS and vanilla JavaScript.

## Run the project
1. Extract `daily_expense_tracker.zip`.
2. Open the `index.html` file in Chrome, Edge, Firefox or another modern browser.
3. Add income and expense transactions using the form.

No installation, server, database or internet connection is required.

## Features
- Add income and expense transactions with date, category and description.
- Dashboard totals for income, expenses, balance and current-month expenses.
- Filter transaction history by month.
- Delete individual transactions.
- Expense category doughnut chart.
- Monthly income-versus-expense chart and yearly summary.
- Export transactions to CSV.
- Automatically saves data in browser local storage.

## Data and privacy
Transactions are stored locally in the browser on the device where the project is used. Clearing browser site data or changing browsers/devices may remove access to those records. Use **Export CSV** to keep a backup.
